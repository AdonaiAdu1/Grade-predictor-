# Student Grade Predictor

## What This Does
Predicts exam scores using simple linear regression based on study hours, previous scores, and attendance.

## Live Demo
**Try it instantly:** [Click here to run on OnlineGDB](https://onlinegdb.com/A5ZoEVRBL)

## How It Works
Uses weighted formula:
- Study hours (40% weight)
- Previous score (35% weight)
- Attendance (25% weight)
